# Reference data

| File | Content |
|---|---|
| `parts.csv` | The five Parts: accession number, DOI, volume-53 start page, label, primary-author pattern |
| `merge_rules.csv` | Variant reference keys mapped to one form |
| `self_citation_patterns.csv` | Key prefixes of references to the Parts themselves |
| `strand_keys.csv` | Foundations classified into the uncertainty and cognitive-styles strands |
| `project_authors.csv` | Authors of the Parts, as they appear in the WoS author field |
| `named_papers.csv` | Papers by the research groups discussed in the article (first author, year) |
| `table1_submitted.csv` | Counts behind the percentages of Table 1 in the submitted manuscript |
